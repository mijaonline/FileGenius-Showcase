# 🧠 FileGenius - Smart File Organizer

![FileGenius](https://filegenius.michaelmondala.site) *(Link to live site)*

## 🚀 About The Project
FileGenius is a Full-Stack Windows application I built to instantly declutter messy directories (like Downloads and Desktop) into organized, categorized folders with a single click.

It features a custom-built GUI, a cloud-hosted Flask REST API, and global payment automation via Gumroad Webhooks. 

**Note: The source code is housed in a private repository as this is a commercial SaaS product.**

## 🛠️ Built With
* **Python** (Core Algorithm & Application Logic)
* **CustomTkinter** (Modern Dark-Mode GUI)
* **Flask & SQLAlchemy** (Cloud Backend & Database Auth)
* **Tailwind CSS** (Responsive Landing Page)
* **PyInstaller** (Packaged .exe distribution)

## ✨ Key Features
* 📂 **Smart Categorization:** Scans file extensions and auto-sorts them (Images, Executables, Docs, etc.)
* 🧹 **Auto-Cleanup:** Deletes empty directories post-sort.
* 👯 **Hashing Algorithm:** Built-in Duplicate File Finder using MD5 hashing to isolate clones.
* ☁️ **Cloud Auth:** Real-time license verification checking Free/Pro/Elite tiers.
* 💳 **Automated Webhooks:** Instant account upgrades via Gumroad API integration.
